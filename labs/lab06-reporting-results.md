# Lab 6: Write the Final Results Section

## Goal

Write a complete SmartPLS results section using exported tables.

## Choose One Report Type

1. Regression results report
2. PLS-SEM results report

## Required Content

Regression report:

- Model specification
- Regression settings
- R-square and adjusted R-square
- Coefficients and significance
- Bootstrapped confidence intervals
- Diagnostics
- Interpretation and limitations

PLS-SEM report:

- Measurement model assessment
- Structural model assessment
- Bootstrapping settings
- Hypothesis testing
- Predictive assessment if used
- Interpretation and limitations

## Deliverable

Use one of:

- [regression-results-report-template.md](../templates/regression-results-report-template.md)
- [plssem-results-report-template.md](../templates/plssem-results-report-template.md)

Submit a 3 to 5 page final results section.
