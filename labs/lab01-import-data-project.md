# Lab 1: Import Dataset and Create a SmartPLS Project

## Goal

Create a SmartPLS 4 project and import the training dataset.

## Dataset

Use:

```text
datasets/smartpls_regression_training_data.csv
```

## Steps

1. Open SmartPLS 4.
2. Create a new project named `SmartPLS4 Regression Course`.
3. Import the CSV dataset.
4. Check the data preview.
5. Confirm that all variables are recognized correctly.
6. Save the project.

## Variables to Find

Observed-variable regression variables:

- `SATISFACTION`
- `USEFULNESS`
- `EASE_OF_USE`
- `TRUST`
- `SERVICE_QUALITY`
- `AGE`
- `EXPERIENCE`
- `GENDER_MALE`

PLS-SEM indicators:

- `PU1`, `PU2`, `PU3`
- `PEOU1`, `PEOU2`, `PEOU3`
- `TR1`, `TR2`, `TR3`
- `SQ1`, `SQ2`, `SQ3`
- `SAT1`, `SAT2`, `SAT3`
