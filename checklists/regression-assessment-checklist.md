# Regression Assessment Checklist

Use this checklist after running SmartPLS regression.

## Model Setup

- [ ] Dependent variable is continuous.
- [ ] Predictors are correctly coded.
- [ ] Controls are theoretically justified.
- [ ] Intercept is included unless explicitly justified.
- [ ] Final sample size is recorded.

## Regression Results

- [ ] Unstandardized coefficients are exported.
- [ ] Standardized coefficients are exported.
- [ ] Standard errors are recorded.
- [ ] t-values are recorded.
- [ ] p-values are recorded.
- [ ] Confidence intervals are recorded.
- [ ] R-square is recorded.
- [ ] Adjusted R-square is recorded.

## Diagnostics

- [ ] QQ plot inspected.
- [ ] Residual pattern inspected if available.
- [ ] Multicollinearity considered.
- [ ] Robust standard errors considered if needed.
- [ ] Outliers or unusual cases discussed.

## Reporting

- [ ] SmartPLS version reported.
- [ ] Standard error type reported.
- [ ] Bootstrapping settings reported.
- [ ] Interpretation uses association language unless causal design exists.
- [ ] Results table and written text match.
