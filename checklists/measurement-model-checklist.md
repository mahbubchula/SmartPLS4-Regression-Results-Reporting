# PLS-SEM Measurement Model Checklist

## Reflective Measurement

- [ ] Indicator loadings assessed.
- [ ] Low-loading indicators justified if retained or removed.
- [ ] Cronbach's alpha reported.
- [ ] rho_A reported.
- [ ] Composite reliability rho_C reported.
- [ ] AVE reported.
- [ ] HTMT reported.
- [ ] Fornell-Larcker criterion reported if required.
- [ ] Measurement model conclusion written before structural interpretation.

## Typical Criteria

| Criterion | Common Guideline |
|---|---|
| Loading | >= 0.708 preferred |
| Reliability | 0.70 to 0.95 often acceptable |
| AVE | >= 0.50 |
| HTMT | < 0.85 or < 0.90 depending on construct similarity |

## Notes

Use theory and measurement quality together. Do not delete items only to improve numbers.
