# PLS-SEM Structural Model Checklist

## Collinearity

- [ ] VIF values exported.
- [ ] High VIF values investigated.
- [ ] Predictor redundancy discussed if needed.

## Path Assessment

- [ ] Path coefficients exported.
- [ ] Bootstrapping was run.
- [ ] t-values reported.
- [ ] p-values reported.
- [ ] Confidence intervals reported.
- [ ] Hypothesis decisions match direction and significance.

## Explanatory Power

- [ ] R-square reported for each endogenous construct.
- [ ] Adjusted R-square reported where useful.
- [ ] f-square effect sizes reported.
- [ ] Practical meaning discussed.

## Prediction

- [ ] PLSpredict considered if prediction is part of the research aim.
- [ ] Q2_predict reported when used.
- [ ] RMSE/MAE comparison interpreted when used.
