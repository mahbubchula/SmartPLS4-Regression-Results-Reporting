# Module 12: Capstone SmartPLS Report

## Purpose

The capstone combines the full workflow into a complete SmartPLS analysis report.

## Learning Objectives

After this module, learners should be able to:

- Complete a SmartPLS regression or PLS-SEM analysis.
- Export and organize results.
- Assess results using transparent criteria.
- Write a complete report section.

## Capstone Options

Choose one:

1. Observed-variable multiple regression in SmartPLS.
2. PLS-SEM model with latent constructs.
3. Regression plus optional logistic regression or NCA extension.

## Required Components

Your final report must include:

- Research question
- Hypotheses
- Dataset description
- Data preparation statement
- Model diagram
- Analysis settings
- Results assessment table
- Bootstrapping table
- Interpretation
- Limitations
- SmartPLS citation

## Report Structure

```text
Title
Research question
Data and variables
Model specification
Analysis settings
Regression or measurement model assessment
Structural/result assessment
Bootstrapping results
Prediction assessment if used
Discussion
Limitations
Conclusion
References
Appendix with exported SmartPLS tables
```

## Final Submission Checklist

- SmartPLS project file saved.
- Dataset file included or described.
- Output tables exported.
- Screenshots saved.
- Results table formatted.
- Interpretation avoids overclaiming.
- Reporting template completed.
- References included.

## Course Completion

After finishing the capstone, learners should be able to conduct and report SmartPLS 4 regression or PLS-SEM results in a professional thesis, article, or research report.
