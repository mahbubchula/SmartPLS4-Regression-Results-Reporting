# Contributing

Contributions are welcome when they improve SmartPLS workflow clarity, result assessment quality, reporting templates, or teaching examples.

## Useful Contributions

- Better SmartPLS step descriptions
- More reporting examples
- Additional reviewer response examples
- New datasets for teaching
- Improved checklists

## Style

- Keep instructions practical.
- Use SmartPLS 4 terminology.
- Avoid unsupported causal claims.
- Explain interpretation in plain language.
- Cite official SmartPLS documentation when adding software-specific guidance.
