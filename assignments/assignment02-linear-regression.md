# Assignment 2: SmartPLS Linear Regression

## Goal

Build and run a SmartPLS multiple regression model.

## Tasks

1. Use `SATISFACTION` as the dependent variable.
2. Include `USEFULNESS`, `EASE_OF_USE`, `TRUST`, and `SERVICE_QUALITY` as predictors.
3. Add `AGE`, `EXPERIENCE`, and `GENDER_MALE` as controls.
4. Run linear regression.
5. Export the coefficients table.
6. Interpret all main predictor coefficients.

## Deliverable

Submit a regression results table and 300-word interpretation.
