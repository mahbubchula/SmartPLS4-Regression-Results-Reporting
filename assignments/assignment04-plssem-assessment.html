Assignment 4: PLS-SEM Results Assessment

Goal

Assess measurement and structural model results in SmartPLS 4.

Tasks

  1. Create reflective constructs from the indicator variables.
  2. Run the PLS-SEM algorithm.
  3. Assess outer loadings.
  4. Assess reliability and AVE.
  5. Assess HTMT.
  6. Run bootstrapping.
  7. Assess structural paths, VIF, R-square, and f-square.

Deliverable

Submit a measurement model table, structural model table, and hypothesis decision table.
