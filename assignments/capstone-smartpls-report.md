# Capstone SmartPLS Report

## Goal

Write a complete SmartPLS results section suitable for a thesis or journal paper.

## Required Sections

1. Research question and hypotheses
2. Data description
3. SmartPLS project/model description
4. Analysis settings
5. Regression or measurement model assessment
6. Structural/result assessment
7. Bootstrapping results
8. Prediction assessment if used
9. Interpretation
10. Limitations
11. SmartPLS citation

## Deliverable

Submit a 5 to 8 page results chapter with exported SmartPLS tables and screenshots.
