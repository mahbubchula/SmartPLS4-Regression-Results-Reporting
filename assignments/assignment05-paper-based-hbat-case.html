Assignment 5: Paper-Based HBAT SmartPLS Case

Goal

Use the shared SmartPLS 4 regression tutorial paper as a model and complete both multiple linear regression and logistic regression analysis.

Dataset

Use:

datasets/hbat_smartpls_regression_case.csv

Part A: Multiple Linear Regression

Model:

X19 <- X6 + X7 + X9 + X11 + X12

Tasks:

  1. Build the model in SmartPLS 4.
  2. Run regression.
  3. Export ANOVA/model fit output.
  4. Export R-square and adjusted R-square.
  5. Export coefficients and standardized coefficients.
  6. Check collinearity.
  7. Check residual assumptions using SmartPLS plots/tests.
  8. Write a results paragraph.

Part B: Logistic Regression

Model:

X4 <- X6 + X7 + X8 + X9 + X10 + X11 + X12 + X13 + X14 + X15 + X16 + X17 + X18

Tasks:

  1. Build the model in SmartPLS 4.
  2. Run logistic regression.
  3. Export fit summary.
  4. Export pseudo R-square values.
  5. Export confusion matrix.
  6. Export coefficients and Wald tests.
  7. Calculate or export odds ratios.
  8. Write a logistic regression results paragraph.

Deliverable

Submit a complete paper-style report with:

  • Model diagrams
  • Exported SmartPLS result tables
  • Linear regression assessment workbook
  • Logistic regression assessment checklist
  • Final results section
  • Limitation paragraph
  • SmartPLS citation

Rubric

Criterion Points

Linear regression assessment 20
Logistic regression assessment 20
Assumption and diagnostic discussion 15
Results reporting quality 15
