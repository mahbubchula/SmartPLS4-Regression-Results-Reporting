# Assignment 3: Regression Assessment and Bootstrapping

## Goal

Assess regression results and use bootstrapping for final inference.

## Tasks

1. Run regression bootstrapping with 10,000 subsamples.
2. Export bootstrap coefficients and confidence intervals.
3. Identify significant and non-significant predictors.
4. Assess R-square and adjusted R-square.
5. Inspect QQ plot and diagnostics.
6. Decide whether robust standard errors are needed.

## Deliverable

Submit the regression assessment checklist and a final interpretation paragraph.
